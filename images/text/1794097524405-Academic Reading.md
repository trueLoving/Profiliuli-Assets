
> 阅读实践操作指南 · Extensive Reading + Intensive Reading

## 1. 核心原则

阅读的目的不是认识文章中的每一个单词，而是逐渐建立独立理解英语材料的能力。

整个阅读过程遵循：

先理解整体，再解决细节；先独立阅读，再借助 AI；先理解文章，再提取知识。

两次阅读承担不同任务：

|阅读阶段|核心目标|主要任务|
|---|---|---|
|First Reading|Overall Understanding|理解文章主题、观点和结构|
|Second Reading|Detailed Understanding|解决语言障碍、理解逻辑、提取知识|

## 2. First Reading — 整体阅读

不依赖 AI，不查词典

目标：在不借助外部工具的情况下，尽可能理解文章整体内容。

### 操作步骤

1. Preview：阅读标题、副标题，预测文章主题。
2. Skimming：快速浏览全文，了解文章结构。
3. Reading：正常阅读，理解每个段落的主要内容。
4. Summary：阅读结束后，尝试总结文章。

### 重点关注

| 关注点           | 需要回答的问题       |
| ------------- | ------------- |
| Topic         | 文章讨论什么？       |
| Main Argument | 作者想表达什么？      |
| Key Points    | 文章有哪些核心观点？    |
| Structure     | 文章如何组织和展开？    |
| Difficulty    | 自己在哪些地方遇到了困难？ |

### 阅读障碍标记

遇到不理解的内容时，先标记，不要立即查询。

| 标记  | 类型         | 含义            |
| --- | ---------- | ------------- |
| V   | Vocabulary | 单词或短语不认识      |
| G   | Grammar    | 认识单词，但不理解句子结构 |
| C   | Context    | 缺少专业知识或文化背景   |
| R   | Reading    | 理解速度慢，需要反复阅读  |

### 第一次阅读记录模板

```
文章讨论的主题。

## 2. Main Argument
作者的主要观点。

## 3. Key Points
- Point 1
- Point 2
- Point 3

## 4. Reading Difficulty
- V:
- G:
- C:
- R:

## 5. Overall Understanding
对文章整体内容的理解。
```

## 3. Second Reading — 精读

可以使用 AI 和词典

目标：解决第一次阅读中发现的障碍，真正理解文章。

### 操作步骤

1. Vocabulary：查询重点词汇和搭配。
2. Grammar：分析复杂句子的语法结构。
3. Context：补充文章涉及的背景知识。
4. Logic：理解段落之间的逻辑关系。
5. Extraction：提取值得长期学习的知识。

### 重点关注

| 模块         | 关注内容                          | 处理方式        |
| ---------- | ----------------------------- | ----------- |
| Vocabulary | 高频词、学术词、实用搭配                  | 查询、理解、筛选    |
| Grammar    | 长难句、从句、非谓语                    | 分析句子主干和修饰关系 |
| Context    | 专业术语、历史、文化背景                  | 补充必要知识      |
| Logic      | 因果、转折、对比、论证                   | 梳理段落逻辑      |
| Extraction | Vocabulary、Sentence、Knowledge | 加入对应知识库     |

### 第二次阅读记录模板

```
- Sentence Structure:
```

## 4. Knowledge Extraction — 知识提取标准

第二次阅读完成后，再决定哪些内容值得进入长期知识库。

|知识类型|进入系统|收录标准|
|---|---|---|
|Vocabulary|Word Bank / Anki|高频、实用、可迁移|
|Sentence|Sentence Bank / Anki|自然、完整、可用于 IELTS|
|Grammar|Grammar Notes|具有代表性的语法结构|
|Knowledge|Knowledge Notes|有助于理解相关领域|

特别注意：

Sentence 的收录标准高于普通阅读笔记。

一篇文章即使有很多漂亮的句子，也不意味着它们都值得进入核心 Sentence 库。

优先考虑能够用于：

- Writing Task 1
- Writing Task 2
- Speaking Part 1
- Speaking Part 2
- Speaking Part 3

的表达。

## 5. 时间安排

建议每篇文章先采用 50–70 分钟的标准流程。

|阶段|时间|产出|
|---|---|---|
|First Reading|15–20 min|整体理解记录|
|Second Reading|25–35 min|详细理解记录|
|Extraction|10–15 min|知识库候选内容|
|Total|50–70 min|完成一次阅读训练|

不要为了完成时间指标而牺牲理解质量。特别困难的文章可以拆成两次完成。

## 6. 实践检查清单

以后每次阅读文章，直接按照这个 Checklist 操作。

1. First Reading

- 不使用 AI 和词典
- 阅读标题并预测主题
- 浏览全文并理解文章结构
- 理解各段核心内容
- 记录 Topic 和 Main Argument
- 记录 Key Points
- 标记 V / G / C / R 阅读障碍

2. Second Reading

- 查询影响理解的重点词汇
- 分析第一次阅读中的长难句
- 补充必要的专业背景知识
- 梳理段落之间的逻辑关系
- 重新确认文章的整体含义

3. Extraction

- 筛选值得积累的 Vocabulary
- 筛选高质量 IELTS Sentence
- 记录必要的 Grammar 知识
- 整理值得保留的 Background Knowledge

4. Final Review

- 不看翻译重新阅读文章
- 确认是否能够理解全文
- 尝试用英语复述文章主要内容
- 记录本次阅读的主要困难

## 7. 后续与 AI 协作的方式

为了保持操作的一致性，建议以后每次阅读都采用以下交互流程：

|你提供的内容|我负责的工作|
|---|---|
|第一次阅读记录|评估整体理解和阅读障碍|
|不理解的段落|分析词汇、语法和背景知识|
|第二次阅读内容|检查理解是否准确，解释逻辑|
|完整文章|筛选高质量 IELTS Sentence|
|最终学习记录|总结本次阅读成果和薄弱环节|

最重要的一条：第一次阅读必须先由你独立完成。 我不会在你第一次阅读之前直接提供全文翻译或文章总结，以免干扰你的独立阅读训练。

今后你只需要告诉我：

- `First Reading`：我会按照第一次阅读标准协助你评估。
- `Second Reading`：我会进入精读模式。
- `Extraction`：我会按照既定标准筛选 Vocabulary、Sentence 和 Knowledge。

这样就形成了一套可以重复使用的 IELTS Reading Workflow。
