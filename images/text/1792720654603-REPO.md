# Repository map

**30-second navigation** for the Omnivuli monorepo. **Cross-app specs:** [`docs/`](./docs/). **Per-app specs:** [`apps/*/docs/`](./apps/).

| I want to… | Go to |
| ---------- | ----- |
| **Change message pipelines / Bot / Dify** | [`apps/conversation-runtime/`](./apps/conversation-runtime/) · specs [`apps/conversation-runtime/docs/`](./apps/conversation-runtime/docs/) |
| **Change tenant admin / Console UI** | [`apps/conversation-console/`](./apps/conversation-console/) · specs [`apps/conversation-console/docs/`](./apps/conversation-console/docs/) |
| **Read PRD / platform architecture** | [`docs/`](./docs/) · index [`docs/README.md`](./docs/README.md) |
| **Track field MVP / out-of-MVP** | [`DEVELOPMENT_PLAN.md`](./DEVELOPMENT_PLAN.md) |
| **Run Phase 1 Telegram demo** | [`examples/phase1-telegram/`](./examples/phase1-telegram/) |
| **Enable plugins at startup** | [`config/distribution/`](./config/distribution/) + [`packages/`](./packages/) |
| **AI agent instructions** | [`AGENTS.md`](./AGENTS.md) |

**Usually skip unless needed:** [`website/`](./website/) (marketing) · [`externals/`](./externals/) (optional Chatwoot/Dify stacks).

---

## Mental model (L0 → L2)

```text
L0 Tool          apps/conversation-runtime/     receive → process → act
L1 Composition   packages/ + config/distribution/   plugins + startup profile
L2 Platform      apps/conversation-console/       tenants, RBAC, Bot Flow UI
                 apps/conversation-model-training/  async training (M5)
Dev-only         apps/conversation-simulator/  fake Telegram channel
                 apps/conversation-business-mock/  fake tenant business APIs (Bot HTTP)
Specs            docs/ (cross-app) + apps/*/docs/ (per-app)
```

## Documentation layers

| Layer | Path | Content |
| ----- | ---- | ------- |
| **Cross-app** | [`docs/`](./docs/) | PRD, platform architecture, Handoff, operator guide |
| **Per-app** | `apps/*/docs/` | API, DB, business flows, L0 contracts |
| **Index** | [`docs/README.md`](./docs/README.md) | Live vs frozen |

**Rule:** Cross-app changes → **`docs/`**. Single-app API/flow changes → **`apps/<app>/docs/`**.

---

## `examples/` vs `externals/`

| Folder | Owns | Use when |
| ------ | ---- | -------- |
| **`examples/`** | Omnivuli compose/scripts (`phase1-telegram`, future `local-dev`) | You want a **minimal shipped demo** of Runtime (+ Console later) |
| **`externals/`** | Upstream Chatwoot/Dify docker stacks | You need **third-party** services locally; not required for Runtime-only smoke |
