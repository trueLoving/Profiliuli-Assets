# 1. Target

## Target Score

| Item | Target |
|------|--------|
| Module | Writing |
| Target Band | **7.5–8.0** |

---

## Target Competencies

To achieve Band 7.5–8.0, learners should be able to:

### Writing Ability

- Organize ideas logically.
- Write coherent academic paragraphs.
- Develop arguments with sufficient support.
- Describe data accurately.
- Compare and summarize information effectively.
- Produce well-structured essays under time constraints.

---

### Language Ability

- Use a wide range of academic vocabulary.
- Use natural collocations.
- Produce varied sentence structures.
- Maintain grammatical accuracy.
- Use cohesive devices naturally.
- Write in an appropriate academic register.

---

### Exam Ability

- Understand different task requirements.
- Allocate time effectively.
- Plan before writing.
- Maintain logical organization.
- Complete both tasks within the time limit.

---

## Success Criteria

The learner should be able to:

- Produce clear and coherent essays.
- Develop ideas sufficiently.
- Make few grammatical mistakes.
- Use varied vocabulary naturally.
- Finish both tasks within 60 minutes.

# 2. Test Overview

## Test Structure

| Task | Time | Description |
|------|------|-------------|
| Task 1 | ~20 min | Describe visual information |
| Task 2 | ~40 min | Write an argumentative essay |

Task 2 contributes twice as much to the final Writing score as Task 1.

---

## Task 1

Possible visuals include:

- Line Graph
- Bar Chart
- Pie Chart
- Table
- Process Diagram
- Map

Focus:

- Describe
- Compare
- Summarize

---

## Task 2

Essay Types

- Opinion
- Discussion
- Advantages & Disadvantages
- Problem & Solution
- Double Question

Focus

- Develop arguments
- Explain ideas
- Give examples
- Draw conclusions

---

| Criterion | Weight |
|------------|---------|
| Task Achievement / Response | 25% |
| Coherence & Cohesion | 25% |
| Lexical Resource | 25% |
| Grammatical Range & Accuracy | 25% |

# 4. Task Analysis

---

## Task 1

### Purpose

Describe and summarize visual information objectively.

### Strategy

1. Identify the main trend.
2. Group similar information.
3. Compare important features.
4. Avoid unnecessary details.

### Required Language Knowledge

- Trend vocabulary
- Comparison language
- Numbers and percentages
- Process descriptions
- Location expressions (Maps)

### Common Mistakes

- Listing every detail.
- Giving personal opinions.
- No overall summary.

---

## Task 2

### Purpose

Evaluate the ability to construct and develop an academic argument.

### Strategy

1. Analyze the question.
2. Decide your position.
3. Plan the essay.
4. Develop each paragraph logically.
5. Conclude consistently.

### Required Language Knowledge

- Academic vocabulary
- Opinion expressions
- Logical connectors
- Complex sentence patterns
- Argument development

### Common Mistakes

- Off-topic responses.
- Weak idea development.
- Poor paragraph organization.
- Repetitive vocabulary.
