# Bot Flow examples

Importable Bot Flow packages (`format: omnivuli.bot_flow`) for Conversation Console.

## Files

| File | Intent | Description |
| ---- | ------ | ----------- |
| [`ecom-assistant.botflow.json`](./ecom-assistant.botflow.json) | `ecom_assistant` | Full e-commerce assistant: menu + login gates + order / product / account / activity + handoff |
| [`booking-assistant.botflow.json`](./booking-assistant.botflow.json) | `booking_assistant` | Service booking assistant: login (ecom OTP) + book / lookup / cancel + handoff |
| [`ACCEPTANCE.md`](./ACCEPTANCE.md) | — | Sim Bot 电商办单验收检查表（#184 / §0.8.A5） |
| [`ACCEPTANCE-booking.md`](./ACCEPTANCE-booking.md) | — | 服务预约助手验收检查表 |

## How to import

1. Open Console → **Bot 流程** (`/tenant/bot-flow-design`).
2. Click **导入** and select the `.botflow.json` file.
3. Review the canvas, **保存**, then **校验** / **发布**.
4. Bind the published Behavior to a **Bot** or **Simulator** channel:
   - Simulator: **模拟器配置** → **分发到 Runtime** → choose **Bot 线** → select this published flow.
   - See [`../local-dev/SIM-AI-BOT-LINES.md`](../local-dev/SIM-AI-BOT-LINES.md) (#187) — no「模拟器行为」page; do not bind AI personas on Bot 线.

You can also open an existing flow and use **导入** in the editor to replace the current canvas (save to persist).

## Package shape

```json
{
  "format": "omnivuli.bot_flow",
  "version": 1,
  "name": "...",
  "description": "...",
  "content": {
    "version": 1,
    "editor": "bot_flow",
    "flow": { "entry_intent_key": "...", "graph_snapshot": { "nodes": [], "edges": [] } },
    "config_json": { "intent_key": "...", "steps_config": [], "flow_runtime": "runtime", "engine": "mock" }
  }
}
```

- Prefer `graph_snapshot` (layout + branches). `steps_config` is recompiled on import/save.
- Secrets (e.g. Dify API keys) are stripped on export.

## Regenerate examples

From `apps/conversation-console/frontend`:

```bash
# 电商助手
GENERATE_BOTFLOW=1 pnpm exec vitest run src/views/Tenant/BotFlowDesign/editor/writeEcomExample.test.js

# 服务预约助手
GENERATE_BOTFLOW=1 pnpm exec vitest run src/views/Tenant/BotFlowDesign/editor/writeBookingExample.test.js
```

Design reference: [`docs/bot-flow-nodes-catalog-and-ecommerce.md`](../docs/bot-flow-nodes-catalog-and-ecommerce.md) §6（ecom）。Booking API profiles live in `conversation-business-mock` domain `booking` + Runtime `app/flow/http_client.py`.
